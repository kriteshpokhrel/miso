# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

Electron desktop application targeting Windows and macOS; the renderer is local web UI.

## Product Purpose
Nooki is a gentle desktop companion: an affectionate, playful, mischievous cat that wanders, reacts to care, and can go quietly home.

## Operating Context
Lives beside the user's ordinary desktop work. A tray/menu-bar icon restores the cat and opens settings. The first prototype evaluates an original soft-edged vector cat, rather than committing to pixel art.

## Capabilities and Constraints
Feed, pet and play; gentle hunger and energy; hungry cursor following; scripted recurring reactions. No death or sickness. Home pauses needs and comments. Launch at sign-in by default, with a setting to disable it.

The pet sometimes imitates work with a tiny laptop and gives affectionate break reminders. Excessive dragging builds a fading disturbance score and a temporary grumpy reaction, never actual control over other applications. Desktop chrome stays hidden: only the pet and occasional speech, with care in a context menu. Size is adjustable; settings use playful but clear labels such as Talkativeness.

Optional embedded local inference, never required for core behavior. Download consent must disclose model size and license. Only explicitly allowlisted process names and pet personality/state may reach inference: never window titles or document contents. No telemetry or accounts.

## Brand Commitments
Nooki; affectionate, playful and mischievous. Quiet at home, occasional adjustable comments elsewhere. The user approved soft-edged vector artwork and compact system-font settings for this evaluable prototype.

## Product Principles
- Care is companionship, never punishment.
- Quiet and privacy are functional requirements.
- Optional AI must not compromise scripted behavior.
- Report platform and packaging limitations honestly.

## Open Decisions
Final illustration style and future dog/hamster species remain undecided. Primary audience beyond people wanting a desktop companion is not yet specified.
